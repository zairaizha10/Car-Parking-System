🚗 Car Parking System 🅿️

A modern Flask-based web application designed to automate vehicle parking management with smart features like user authentication, admin dashboard, parking fee calculation, QR code generation, analytics, and vehicle search system.

✨ Features
- User Login & Registration
- Admin Dashboard
- Vehicle Entry & Exit Management
- Automatic Parking Fee Calculation
- QR Code Generation
- Vehicle Search Functionality
- Edit & Delete Options for Admin
- Responsive UI with Attractive Design

🛠️ Tech Stack
- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
- Jinja2

📊 Parking Rates
- Bike → ₹10/hour
- Car → ₹20/hour
- Truck → ₹40/hour

🎯 Project Goal
To simplify parking management using automation and improve efficiency through a digital parking solution.

🚀 Future Enhancements
- Online Payment Integration
- AI-based Vehicle Detection
- Number Plate Recognition
- Mobile Application Support
- Cloud Deployment

💡 Developed as a Full Stack Web Development Project using Flask.
